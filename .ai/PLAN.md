# 下一步

## 完成首次 npm 发布

本地运行包和三条 GitHub 工作流已实现。按[发布指南](../docs/releasing.md)依次完成：

1. 确认包名权限与代码许可、仓库公开时机；首次通过本机交互登录和 2FA 创建 npm 包。
2. 配置 npm trusted publisher、GitHub 环境审批，并在用户授权后发布候选。
3. 验收已发布 npm 版本的真实桌面安装、阅读、升级和卸载数据保留。
4. 提供验收证据，手动提升稳定 marketplace。

其他系统、架构和宿主在实际环境验收后再列入支持范围。

## 后续功能

- **基础剧情搜索，未开始**：唯一一个模型可见工具，检索名称、别名、分类、有来源的简介及可靠关键词。结果卡片进入对应篇目列表，搜索本身不写进度；卡片字段在该任务开始时确认。
- **介绍与安装网站，暂缓**：只展示项目、版本、下载和安装步骤，不提供在线阅读、正文代理或远端进度服务。域名与部署另行授权。

当前任务不启动上述功能或自动发布。现有实现与验证结果见 [STATUS](STATUS.md)。

# 当前技术决定

本文件保留仍影响实现的选择、依据和维护条件。业务规则见 [需求](../docs/requirements.md)，接口与存储见 [接入说明](../docs/integration-notes.md)，当前交付状态见 [STATUS](STATUS.md)。

## 职责与来源

阅读由本机服务提供，不调用模型。React 管页面与交互，domain 管字数／修订，data 管 PRTS 请求与解析，storage 管记录／缓存，server 管服务和协议适配。使用现有 SDK、SQLite 和原生动画 API，按真实复用需求建立模块边界。

目录只来自 PRTS 剧情一览正文及其明确转引的导航，保留稳定 ID 与源顺序。扫描源字段后选择简单或复杂分支流程；人物与图层状态按分支隔离，共同后续只处理一次。固定源名称、兼容白名单、资料索引和图层坐标的依据及维护入口集中在 [PRTS 维护规则](../docs/maintenance.md)，未知数据保留明确错误。

## 进度与持久化

打开剧情后准备该部全部正文以取得字数分母；准备只写公共缓存／统计，实际打开正文才登记阅读并迁移旧修订。最后位置和最远进度分别保存，避免续读与完成度互相覆盖；未知分母不当作零。

阅读记录、内容缓存和字数索引使用独立 SQLite 存储，以支持多进程事务及分别清理。缓存代次和 historyToken 阻止迟到请求恢复已清数据；旧 JSON 按需迁入并保留源文件，迁移标记防止重复导入。内部模块拆分不改变已有磁盘和工具契约。

## 人物与图片

姓名保留原文，身份与场景图层分别处理。多人匹配优先使用精确资料名／干员 ID，再使用同篇同分支的独立单资源展示；不能以沿用其他角色的画面制造身份冲突，也不能跨篇、跨分支或跨造型推断。默认图必须有同角色同造型的来源依据。具体证据和反例见 [立绘说明](../docs/portrait-speaker-evidence.md)。

默认立绘与原场景使用统一双选控件，让用户能区分发言人和场景资源；查看原场景不代表身份已经确认。无图、身份不确定、解析错误与网络失败分别保留，只有网络失败显示重试。正常图片只保留来源，减少重复诊断对阅读的干扰。

封面按明确源资料定位，统一 1560:500 外框。两个同名特殊合集缺少唯一源图，因此按稳定 ID 区分应用标题并使用原创意象封面，常驻标明“非官方图片”；源分组改变时重核 ID 与成员。批准尺寸、资料来源见 [封面要求](../docs/requirements.md#封面)。

图片保留原始字节和透明通道，经 app-only 元数据分段传输。20 MB 原图、32 层组合、60,000,000 字符组合及分段预算用于约束解码、协议和页面内存，参数与维护依据见 [图片与传输预算](../docs/maintenance.md#图片与传输预算)。

## 页面生命周期与宿主布局

位置观察、保存队列和动画分别处理生命周期，取消或迟到导航不能覆盖当前页面；一次保存失败也不能跳过后续排队写入。设计预览直接复用正式 UI，避免维护另一套状态与样式。

原生 View Transition 截图可能覆盖模态 dialog，z-index 无法解决。设置打开期间直接更新正文并恢复位置；打开设置结束已有转场，关闭时恢复触发按钮焦点。悬停浮层的短关闭延迟仅用于跨越姓名与浮层的间隔，点击固定、触摸和键盘仍是独立操作路径。

设置滑入 320ms 与悬停关闭延迟 120ms 来自已确认的界面节奏及跨越浮层间隔的需要，分别维护于共享样式变量与 Reader 的悬停逻辑；调整时复查减少动态效果、连续操作及焦点终态。

inline 搜索采用自然文档高度，让 SDK 的尺寸观察随晚到结果更新；不叠加自定义观察器或固定大高度。fullscreen 和目录／正文使用受限视口与内部滚动，返回结果后恢复对应布局。初始化、context 更新及显示模式请求返回的实际模式分别处理，不能把请求视为宿主已接受。搜索在偏好载入前跟随宿主主题。

## 搜索与目录简介

唯一模型可见工具 `reader_search` 只支持名称、篇目和人物实际出场。组织、国家与事件由 AI 查证剧情名称后批量定位，不建立关系索引、RAG 或全库台词检索。

搜索按需读取目录及 PRTS [主线出场表](https://prts.wiki/w/剧情出场人物一览/主线)／[活动出场表](https://prts.wiki/w/剧情出场人物一览/活动)，复用 metadata 缓存及清理代次。源页来自实际核对的 PRTS 入口，表头、行结构或目录关联变化时须复核解析，不静默跳过不兼容行。人物精确匹配源表名字，保留疑问号，不猜匿名身份。

简短公共结果进入 structuredContent，完整卡片和命中篇目进入 `_meta.readerSearch`；不把私人记录、出场表或全文交给模型筛选。搜索不登记阅读，显式目录目标优先于自动续读。

整部剧情简介只显示在篇章目录，读取 [活动导语模板](https://prts.wiki/w/模板:活动信息/quote)与[主题曲关卡一览](https://prts.wiki/w/关卡一览/主题曲)。保留来源和段落，无条目隐藏，失败可重试，不生成梗概。主线响应式重复文字仅在内容一致时去重。

## 运行包与发布

GitHub 保存源码与 CI，npm 保存内嵌生产依赖的完整运行包，稳定 marketplace 固定精确 npm 版本。系统 Node 是运行前提；正式入口只使用 PRTS，源码和独立开发副本保留 fixture。记录、内容缓存和本机配置不进入发行物。

当前流程为 main push → Ubuntu Check 成功 → 同提交的 Windows 验收与草稿 → 一次 Publish release → npm latest、正式清单和回执。使用通过 Check 的固定 SHA，避免排队期间改取最新 main；只消费已经验收的同一 tgz，避免发布时重新构建。next、独立 promote 和第二次环境审批已退出流程，操作及恢复见 [发布指南](../docs/releasing.md)。

固定标签记录源码、integrity 和原验收运行。中断复用原 artifact，只补缺失附件；相同版本同 hash 可继续收尾，不同 hash 立即失败。跨 npm／GitHub 的写入无法原子完成，部分成功后重跑原作业恢复，不回退公开包或覆盖既有版本。

1.1.0 上传已被 npm 接收，但 Validating 超过原五分钟可见性等待，需在版本公开后重跑收尾。因此明确版本暂时 404 的等待上限改为 20 分钟，Publish release 作业上限改为 30 分钟；查到即继续，不固定等满。明确版本已存在后的旧／缺失 latest 回读仍保留五分钟，两个阶段及准备收尾共用作业时限。轮询间隔 10 秒、单请求最多 15 秒且不超过剩余预算；权限、解析和 integrity 错误立即失败。这些是本项目基于实际延迟选择的有界预算，不是 npm 的 SLA；调整时复核真实日志与作业总时限。

## 验收工具的 Windows 兼容

- tar 解压通过子进程 cwd 传递目标目录，并预先解析归档绝对路径，避免命令参数丢失中文；保留实际中文路径回归。
- 握手失败后等待 transport 的公开关闭事件再清理目录，避免 SDK 异步关闭与 Windows cwd 锁竞争。关闭上限 5 秒来自锁定 SDK 两段各 2 秒的退出宽限及事件余量；升级 SDK 时复核关闭实现。
- 临时目录删除使用原生 fs.rm 的 5 次、100ms 退避，持续锁定仍失败。保留原始验收错误和清理错误，清理完成后才写成功报告。
- 冷缓存 npm 安装与 MCP 握手分阶段。安装明确关闭 stdin，并校验缓存内包身份、bin 和 realpath；由系统 Node 直接启动实际安装产物，MCP 管道不经过 npm 包装进程。Windows 运行记录曾出现包装层等待 stdin 的现象，不据此承诺 npm 包装层自身的 stdio 兼容性。
- 实际冷安装曾在约 107 秒成功、120 秒被终止，因此安装单独使用 300 秒预算；其他 npm 命令维持 120 秒、MCP 握手维持 60 秒。离线安装关闭 update-notifier，输出 timing／verbose 日志用于定位耗时。完整 PRTS 验收复用同次冷安装，不减少断言或跨运行复用热缓存。

## 验证策略

源代码协议测试通过 projectRoot 边界使用隔离原创 HTML，使 `check` 能在没有 dist 的干净源码中运行；实际包验收另读真实 global／search HTML，并检查清单、解包 bin 和 npm 安装 bin 三种入口的完整契约一致。

触摸回归保留可信 CDP 事件、原生惯性、scrollend、滑动距离和之后一次卡片点击。原快速 touchMove 注入曾导致后续 tap 不生成 click；按 requestAnimationFrame 节奏发送后恢复，因此修正测试注入时序，不修改产品点击行为，也不依靠强制偏移或重复点击。

SDK iframe 检查使用实际构建 HTML、MCP 资源／工具和官方桥接，inline 高度只由尺寸通知决定，fullscreen 固定到实际窗口。Ubuntu Check 与 Windows 发包验收均执行这套回归，失败时保留报告和截图；它证明协议和布局，真实桌面、其他宿主和其他平台分别验收。

## 网站与原创素材

网站是独立静态构建，复用 ReaderApp、领域规则和工具验证，使用网站专用占位来源和独立会话记录，不把 SQLite／PRTS 搬进浏览器。演示主页使用可选启动设置，正式入口仍默认续读；分类跳转只滚动自身容器，避免带动外层网页。

imagesAvailable 与 sourceLabel 让有素材的样例沿用现有图片控件并准确标注来源，不冒用 PRTS。v2 会话键隔离旧演示；预置字数锚点来自固定样例，仅用于演示，重置恢复预设，修改内容时同时核对 seed、续读和测试，不写死展示百分比。

滚动演示和交互阅读器各自维护状态。分镜按原生滚动距离推进、停留和倒放，参数集中在 `website/walkthrough-timing.ts`；这些距离来自原创画面，不是游戏数据，改动布局时重核完整停留画面与缩放后的终态。减少动态效果和低高度使用静态说明。

首屏采用静态图标与紧凑文字。六张线描封面和动物兔子是示意素材，原图、编辑输入及完整提示词随仓库保存；运行时只加载压缩副本。画幅、背景色、图片尺寸和窗口留量服务当前原创构图，替换素材时复查比例、透明通道及四种窗口双主题。网站不使用官方截图、立绘、CG 或转载剧情，Pages 部署与 npm 发布独立。

封面背景色 #16232c、768px 兔子图及体验窗口的 150px／210px 顶部留量来自当前原创素材与响应式外壳，不属于 PRTS 数据。颜色与留量维护于网站样式，图片尺寸见素材记录；替换图片或调整外壳时复查完整显示、透明背景与低高度窗口。

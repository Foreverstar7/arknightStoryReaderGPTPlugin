# AI 协作目录

根目录 `AGENTS.md` 是协作入口；本目录用于跨对话接续工作，不是插件运行目录。

| 文件 | 维护内容 |
| --- | --- |
| `STATUS.md` | 当前真实状态、已验证结果、阻塞项和下一步 |
| `PLAN.md` | 切片依赖、验收条件和完成状态 |
| `DECISIONS.md` | 新决定的原因与影响 |
| `START_PROMPT.md` | 新仓库首次开发对话的具体 prompt |
| `local/` | 本机临时资料，已被 Git 忽略，按需创建 |

上述 Markdown 以及需求、设计应提交。不要忽略整个 `.ai/`，不要将完整聊天记录或敏感运行数据加入协作文件。

更新以实际变化为准。状态摘要写清“做了什么、如何验证、还缺什么”，不需要逐条复述工具调用或维护额外日记。

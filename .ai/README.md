# 协作记录

- [STATUS.md](STATUS.md)：当前实现、已有验证及尚未验证的边界。
- [PLAN.md](PLAN.md)：未完成事项、依赖和完成标准；完成后移除对应待办。
- [DECISIONS.md](DECISIONS.md)：仍影响实现的选择、依据和维护条件。
- `local/`：已忽略的本机日志、截图、实验和临时交接资料，不要求协作者拥有。

业务行为以 [requirements.md](../docs/requirements.md) 为准，协作约定见 [AGENTS.md](../AGENTS.md)，维护命令见 [验证指南](../docs/testing.md)与[网站说明](../docs/website.md)。

仅更新会影响协作者后续行动的信息，直接替换失效结论，不追加重复时间线。本机空间、临时服务占用、逐轮操作和会话授权留在本机日志；保留有用的复现步骤、共享验证依据与关键兼容限制。

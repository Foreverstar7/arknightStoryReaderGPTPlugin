回归覆盖清图片／清全部内容、无额外源请求、重试成功、阅读记录不变。原始失败日志为 `integration-transfer-before.log`（Missing expected rejection），修复后专项及全套通过。封面专项测试显式隔离正文准备以控制公开取数；真实准备由 S4 场景和下方 SDK 联合检查覆盖。

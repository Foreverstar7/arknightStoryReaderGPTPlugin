# S3 目录与按需图片实测

核对：2026-11-01；本机版本 0.1.9。S3 首个可操作切片已完成。完整目录已收录，正文语法与资料字段仍按实际打开／必要样本逐步验证，不宣称整库兼容。

| --- | ---: | ---: |
| 主线剧情 | 19 | 435 |
| 活动剧情 | 98 | 1321 |
| 合计 | 117 | 1756 |

保留特殊、四月辑录、集成战略、生息演算等跨行分组，分别保留类型与源顺序。特殊条目使用含分类的 ID，避免与普通活动同名碰撞；既有 `prts:骑兵与猎人` 和篇目 ID 不变。没有沿页脚扩展密录、干员专属目录，也没有为获得目录或分母下载这些正文。目录扩展后，各探针显式选「骑兵与猎人」，不再假设它是第一张卡片。

本轮生产接入采用 PRTS 当前播放器实际使用的 [人物资源 JSON](https://torappu.prts.wiki/assets/avg/character.json)（本轮 1711087 字节）。已实际读取 [播放器入口](https://prts.wiki/w/Widget:StoryPlayer?action=raw)及公开的 context／StoryPlayer bundle 核对 body、index、alias 与表情组合逻辑，没有执行或复制源站 bundle。另读取旧 [Data_Link](https://prts.wiki/w/Widget:Data_Link?action=raw)（724908 字节）、[Data_Char](https://prts.wiki/w/Widget:Data_Char?action=raw)（1025302 字节）作为格式对照；产品没有把旧 CSV 当作当前人物组表。CG 按剧本引用查询 [Data_Image](https://prts.wiki/w/Widget:Data_Image?action=raw)（201460 字节）。这些是少量映射文件，不是整库图片。

简介从所选篇目的父关卡页 `关卡描述` 取首段原文；后面的作战限制不混入简介。无该字段则隐藏；不兼容模板明确报错，可重试。GT-1 的来源为 [日正当中](https://prts.wiki/w/GT-1%20日正当中?action=raw)，不是生成摘要。只在篇目卡进入可视区域后请求，行动前／后共享一个关卡元数据缓存。

封面只认活动页 `标题图文件名`，通过 MediaWiki `action=query&prop=imageinfo` 解析实际地址。已验证 [骑兵与猎人活动页](https://prts.wiki/w/骑兵与猎人?action=raw)中的「骑兵与猎人-预告公告.png」。缺少可确认字段的主线／特殊入口显示“暂无封面”，不拿其他图片顶替；更多资料格式仍待补。

## 图片路径与触发

人物引用先解析映射的 body/index 或精确别名，再取得单图或 `face_overlay` 的底图与表情层。不按显示名搜索、不由 `#n` 拼图片名、不对不存在的序号回退第一张。多人槽位和焦点仍保留；只存在一种不同场景资源时，可查看该处的场景立绘，界面明确不据此识别显示名。多个不同资源、无资源或映射歧义时明确不给立绘。匿名姓名保持匿名，分支状态沿用独立继承／一致合流规则；补齐 `CharSlot` 仅调整视觉参数时不得清掉原槽位，以及 `char_empty` 清空的回归。

| `char_220_grani#5` | 1024×1024 | 270110 |
| `ac1_0` CG | 1500×844 | 619428 |
| 骑兵与猎人封面 | 1560×500 | 950892 |
| `avg_npc_2321_1#6$1` | 底图 1152×1152＋92×92 表情 | 1044994＋27797 |
| `avg_npc_2321_1#6$2` | 底图 1152×1152＋92×92 表情 | 666097＋27810 |

已用正式 `ImageLayers` 组件在隔离 Edge 中实际渲染后两组资源，实看持盾／无盾差异、表情位置和透明背景。浏览器对格拉尼 PNG 解码后核对透明角落 alpha=0，且有非透明人物像素。原 PNG 不转 JPEG，也不读取／显示透明区域的 RGB。原生 SVG `<image>` 按映射坐标组合，未引入图像处理依赖。

- 默认手动：姓名 hover 只有提示，滚过 CG 不取图；点击姓名／CG 后才获取。无资源和多资源歧义在取图片前结束。
- 自动：姓名 hover 取图；CG 用真实正文滚动容器的 IntersectionObserver，在距可视区 240 CSS px 内触发。不会因打开正文遍历全部图片。600px 高窗口下首篇两张 CG 均可能在附近范围；低高度用例确认远处 CG 未提前请求。
- 封面与正文开关独立：卡片实际进入目录滚动容器可视区才加载，离屏的骑兵卡初始不请求封面。
- 图片加载／失败／重试留在原控件中。立绘浮层使用原生 React portal，随锚点定位并限制在视口内；Escape 恢复姓名键盘焦点，点击其他位置（包括顶栏设置）收起。低高度浮层可内部滚动。设置开关先显示当前选择，保存失败回退，不再等待异步存储后才反馈勾选；真实模式设置中不再显示 fixture 标记。

## 缓存、工具与阅读记录

公开缓存分为 `text`、`prts`、`mapping`、`metadata`、`images`；SQLite 阅读记录在独立 `reading/`。映射、元数据与 PNG 按最后访问时间保留；同一 URL 图片只缓存一份，并合并并发取数。清图片保留映射；清全部内容清掉映射／资料；两者均保留阅读位置、最远进度和已知字数。清理中的旧请求不重新填回新一代图片缓存。当前进程只保留段落字数索引与图片资源引用；清内容后滚动保存不重新下载正文。

新增 `reader_image` 与 `reader_chapter_info` 两个 app-only 工具，总计 9 个；唯一模型可见搜索仍留 S5。图片请求由服务端限制到已解析的篇目／资源及公开 PRTS 来源，检查 HTTP、大小、PNG 签名和 MIME。UI 不直连 PRTS。依据 [OpenAI 当前工具返回契约](https://developers.openai.com/plugins/reference)，图片层放在工具结果 `_meta.readerImage`，`structuredContent` 仅含尺寸／来源；官方 SDK `callServerTool` 读取这些数据后用 data URL 显示，未增加外域 CSP。

隔离实时探针只请求 15 个公开 URL，全部 HTTP 200；第一次明确图片触发前 4 次请求只含目录、关卡页与所选正文。重复人物／CG 读取新增源站请求为 0；已缓存真实图片在注入断网后重启可读。清图片不清记录，清全部内容后继续保存位置新增请求为 0。断网是注入 fetch 失败，未断开物理网络。完整原文、图片和 JSON 日志位于忽略目录 `.ai/local/prts/s3-live-UWLw5E/`，不随源码或插件分发。

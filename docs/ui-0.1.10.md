## 卡片与界面

- 篇目标题使用原生按钮，CSS `::after` 将点击范围覆盖整卡；简介重试按钮是同级控件，显示在覆盖层上。没有嵌套按钮，也不为外层容器仿制按钮键盘语义。
- 实际点击标题、简介、进度及边缘留白，每次从篇首打开；从读到后面的位置返回目录后仍从篇首进入。鼠标拖轴和 CDP 派发的原生触摸横滑只改变轴位置，随后 Enter／正常触摸仍可打开。后续键盘 click 不受上一拖动抑制影响。
- 简介请求前两次显式注入 HTTP 503，分别用鼠标和 Enter 重试；期间没有正文请求，成功显示真实简介后再点简介才进入正文。
- 浅深主题下比较两种卡片及内部文字的背景、边框、文字颜色、transform、阴影和边界框，hover 前后完全一致；鼠标为手形，键盘焦点框可见，篇目焦点覆盖整卡。
- 七个分类入口在 320px 下换行，全部位于视口内且可跳到对应标题；中等、桌面、低高度同样逐一点击。没有整体 transform 缩放。
- 已在隔离 Edge 实际打开原始交互稿并进入篇目轴，对照正式页面及截图。保持三页、交错轴、正文宽度与固定顶栏／来源条、封面迁移、正文揭幕和方向相反的平面柔边扫过。可观察差异为最新确认的七分类和取消卡片 hover 变化；参考稿的外包装、示意封面和模拟进度不作为生产数据。

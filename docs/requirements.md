# 阅读行为与功能范围

本文件描述当前实现。代码版本见 `package.json`；发布与验收状态见 [STATUS](../.ai/STATUS.md)。

## 范围

- 阅读来源为 [PRTS 剧情一览](https://prts.wiki/w/剧情一览)正文及其明确转引的剧情导航，不另建干员密录／专属剧情目录。
- 同一容器内有剧情总目录、篇目列表和正文三个页面。支持全部分支、按需图片、本机续读、字数进度与缓存管理。
- 阅读不调用模型。当前十个工具均供页面使用，尚无模型可见的搜索工具。
- 不提供批注、EPUB／MOBI、跨设备同步、整库离线包、后台定时同步或全库台词检索。

## 总目录

- 分类顺序为主线、支线、故事集、集成战略、生息演算、四月辑录、其他；类内保留源站顺序。普通“剧情”合集归故事集，零散特殊入口归其他并保留具体类型。
- 每张卡片对应一部剧情，显示封面、名称、类型与进度；点击始终进入该部篇目列表。分类导航定位到对应分区。
- 返回主页恢复本次会话的目录浏览位置，窗口变化时优先保持同一段卡片；已经在主页时不跳到顶部。
- 卡片 hover 只显示手形，不变色、不上浮；键盘焦点可见。封面重试是独立按钮，不触发进入剧情。
- 首页进度为白底圆环。从未实际阅读显示 0%；有记录但分母或修订尚未核实时显示短横线与可访问说明。
- 每次重新打开阅读器检查一次目录，有缓存先展示再更新。手动“刷新目录”与自动检查共用流程，重复请求合并；失败保留可用目录并允许重试。
- 目录刷新不重新下载所有正文／图片，不改变阅读记录、设置或当前正文位置。

### 封面

- 封面进入可视区域时自动获取，独立于正文图片开关。主页和篇目页统一使用 **1560:500** 外框。
- 标准 1560×500 原图完整显示；主线 EP00—EP04 的 512×512 原图、通用危机合约的 463×121 图完整等比显示并填充背景，不裁切或拉伸。
- 四月辑录通过 APF-YYYY/NBT 与活动索引的年份链接定位横幅；图片 URL 经 MediaWiki imageinfo 取得，不拼接地址。
- `prts:主线剧情/特殊 · 剧情` 显示应用文字封面“主线补充剧情”；`prts:活动剧情/特殊 · 剧情` 显示“活动补充剧情”。按稳定 ID 区分，不按同名标题猜测。
- 其他未经批准的尺寸显示“封面尺寸待适配”。来源缺失、网络失败和解析不兼容分别显示，不合并为“暂无封面”。

## 篇目列表

- 篇目沿水平主线上下交错，从左到右排列；通过拖动、横向滚动或浏览线查看，不放前后翻页按钮。
- 每篇显示编号、名称、可取得的 PRTS 关卡简介和阅读百分比，不放缩略图。没有简介时隐藏该行。
- 整张篇目卡片可点击并从篇首打开；拖动不误触。简介的“重试”只重试简介。
- 有阅读记录时，页头显示“继续阅读 + 章节名称”，恢复该部剧情最后位置。
- 页面显示正文准备进度和准备完成后的总字数；部分失败保留成功结果并可重试。
- “清除本剧情阅读记录”经页面确认后只清该部记录，保留其他剧情、设置、缓存与字数统计，并留在当前目录。

## 正文与导航

- 正文纵向连续滚动；每段发言只显示一次姓名，右侧可含多段文字。旁白与对白正文左对齐。
- 左侧篇目列表标记当前章节，点击其他篇目从篇首打开；窄窗口收为可展开侧栏。
- 顶部“最近阅读”指向最近实际打开的文字篇目，浏览其他目录不会替换；点击恢复最后位置，正在阅读同一篇时不重建页面或跳位。
- 主页上的“篇章目录”入口指向最近实际阅读的剧情。无阅读记录时隐藏相关入口。
- 重新打开阅读器优先恢复上次章节与段落位置；没有可恢复记录时显示目录。
- 正文末尾提供上一篇／下一篇。顶栏显示本篇与全剧情进度，并保持设置入口可用。
- 所有选项及分支按组保留，共同后续只展示一次；分支独立维护人物与图层状态。
- 视频显示明确的 PRTS 来源入口，不内嵌播放。纯视频篇不创建文字记录或改变最近阅读；混合篇正常保存文字进度。

### 图片与人物

- 默认 hover 姓名只提示“点击查看立绘”，点击后请求并显示；再次点击、点击外部或 Esc 关闭。正常浮层仅显示图片和 PRTS 链接。
- 开启“自动显示图片”后，hover 姓名取得立绘，滚动接近 CG 时取得并原位显示；不开启时由按钮触发。关闭开关不删除缓存。
- 显示姓名保持原文，包括匿名姓名。人物资源由场景槽位／来源映射决定，焦点不等于说话者。
- 多人场景只有精确资料名、明确干员 ID 与场景唯一资源同时对应时才展示立绘；不能确认时使用中性占位，不靠相似姓名或逐角色特例猜测。
- 优先原图；有同一资源组、同一造型的明确默认依据时才用默认立绘。默认图、占位、加载失败有不同提示与重试。
- CG 支持 Image／ImgEffect、CGItem 静态图层及 largebg／verticalbg 的 cggroup 拼接；保留透明通道和完整图层。常规舞台背景、imagegroup 与动态演出不作为正文 CG。

## 字数、位置与进度

整体进度为各篇已读字数之和除以该部剧情完整的文字总字数，不对篇目百分比取平均。

- 字数按非空白 Unicode 码点计，包含对白、旁白、选项及全部分支；姓名、界面标签、演出指令、图片、视频和来源说明不计入。共同后续只计一次。
- 打开某部剧情后，以最多两篇并发准备该部全部正文，取得分母；目录先展示，用户可边加载边阅读。不预取其他剧情或正文图片／映射。
- 准备只更新公共缓存与字数，不写阅读记录。离开剧情停止排队，已发请求可完成；再次打开复用缓存并补取缺失篇目。
- 缺失或解析失败的正文保持未知，不当作零字数。纯视频明确排除在文字分母之外，含视频剧情的进度注明只统计文字。
- 每篇按最远位置估算已读字数，回看不倒退、重读不重复累计；未打开的中间篇目不会因跳章而算作已读。同篇拖到后方会推进最远进度。
- 最后位置与最远进度分别保存：续读跟随最后位置，百分比使用最远位置。只有完整到达末尾才显示 100%。
- 位置以段落标识与段内比例保存，不只存滚动像素。正文修订后先匹配确认内容；不能可靠恢复时回到较早确认位置或篇首，并保留迁移信息，不伪造已读比例。

## 设置与数据管理

- 主题提供“主题跟随系统”和“深色模式”开关；跟随时后者反映有效主题并禁用。关闭跟随后保留当前有效主题，偏好持久保存。
- 内容缓存默认按最后使用时间保留 7 天，可调整为 1—365 天；无总容量上限。关闭应用期间不运行定时清理。
- “刷新本章”重取当前正文并更新字数；内容变化只在实际打开正文时迁移记录，后台准备不迁移。
- “清理图片缓存”只清图片；“清理剧情文本和图片缓存”清正文、资料、映射和图片。两者均保留阅读记录、偏好和公共字数。
- 清全部内容时停止准备队列，不立刻补下载；重新打开或主动重试后才恢复获取。清理前的迟到请求不能回填。
- “清除全部阅读记录”经确认后回到主页并隐藏最近阅读；保留偏好、缓存和公共统计。清除前的旧页面保存不能使记录复活。

## 布局与动效

共享样式控制颜色、字号、间距和时长。通过重排、换行和侧栏收起适配窗口，不整体缩放画布。

封面在目录卡片与篇目页页头之间迁移，正文纵向揭幕；相邻篇目用方向相反的横向渐进替换。顶栏和来源提示不参与内容转场；连续操作、缩放和减少动态效果均保持相同终态，不采用铺满屏幕的封面放大或 3D 卷页。

[界面预览](design/README.md)直接使用当前组件和样式。界面验收覆盖 320px、中等、桌面和低高度窗口，以及双主题、键盘、触摸和减少动态效果。

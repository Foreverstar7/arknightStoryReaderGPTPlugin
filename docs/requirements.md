# 阅读行为与功能范围

本文件描述当前实现及明确标注的已确认待实现需求。代码版本见 `package.json`；发布与验收状态见 [STATUS](../.ai/STATUS.md)。

## 范围

- 阅读来源为 [PRTS 剧情一览](https://prts.wiki/w/剧情一览)正文及其明确转引的剧情导航，不另建干员密录／专属剧情目录。
- 同一容器内有剧情总目录、篇目列表和正文三个页面。支持全部分支、按需图片、本机续读、字数进度与缓存管理。
- 阅读不调用模型。唯一模型可见工具为 `reader_search`；其余十一个工具只供页面使用。
- 不提供批注、EPUB／MOBI、跨设备同步、整库离线包、后台定时同步或全库台词检索。

## 剧情搜索

- 唯一模型可见工具 `reader_search` 支持剧情名称、篇目编号／标题、人物实际出场三类查询，以及批量定位 AI 已找到的一个或多个剧情名称。结果按所属剧情聚合为一张或多张卡片，点击进入对应剧情的篇目列表；显式搜索目标优先于自动续读。只返回现有目录可对应的剧情，不另建干员密录／专属剧情目录。
- ChatGPT 桌面搜索卡片优先通过官方深链进入当前安装来源的侧栏阅读器，并保留命中篇目标记；搜索卡片留在对话中。阅读器首次打开或已打开时均响应目标，重复点击同一剧情可从正文返回篇目目录；跳转前完成当前阅读位置保存，连续请求只应用最新目标，保存失败时保留当前页面并可重试。不支持该入口的宿主及浏览器／网站预览保留当前容器中的阅读流程；宿主明确拒绝侧栏跳转时显示重试和显式“在当前窗口打开”。
- 人物查询只查实际出场，不包含仅在他人对白或旁白中被提及。以 PRTS 明确收录的出场记录为依据，不用简介关键词或模型记忆推断人物出场。
- 出场资料使用 [PRTS 剧情出场人物一览](https://prts.wiki/w/剧情出场人物一览)等 PRTS 出场资料，接受源站更新滞后，不另行补齐超出 PRTS 收录范围的出场。未命中表示当前资料未找到，不据此断言人物从未出场；不把网络或解析失败当作无结果。
- 搜索只读取完整目录和按需取得的人物出场表，不依赖已下载的正文；本地缺少资料时从 PRTS 取得并缓存。已有有效缓存时可断网查询；冷缓存且取数失败时显示来源错误，不当作无结果。页面支持结果分页和失败重试，不提供常驻的“刷新搜索资料”按钮或新增设置入口；资料获取沿用现有缓存规则，底层保留强制刷新能力。清理内容缓存保留阅读记录。
- 搜索本身不写阅读记录，也不下载正文或图片；封面由卡片进入可视区后按需取得。模型只收到简短结果，完整卡片及命中篇目数据通过页面专用 metadata 传递。不增加全库台词检索、人物提及检索或独立模型 API 调用。
- 搜索结果卡片不显示剧情简介；整部剧情的简短介绍只添加到对应剧情的篇目列表（篇章目录）页，具体规则见下文。
- 组织、国家和事件的关联由 AI 借助可用搜索能力查找 PRTS 依据，取得剧情名称后用 `reader_search` 定位卡片。工具不自建这三类关联索引，也不把剧情名命中视为组织／地点／事件关系已获工具确认。卡片显示封面、名称、类型、篇目数与适用的命中篇目数，不显示简介或私人进度。

## 发行方式

- 修改代码并更新版本后推送 main，Check 的 Ubuntu 检查通过后才调用 Prepare release draft，使用通过检查的同一个提交 SHA 在 Windows 构建和验收，成功后准备固定标签与 Release 草稿。每个版本唯一的人工发布确认是点击 Publish release。
- 每个新版本在 `docs/releases/X.Y.Z-notes.md` 维护发行标题与正文；草稿从固定验收提交读取该文件，自动填入 Release 标题和正文并附加源码／归档验收信息。说明缺失、空白或版本不匹配时不能创建标签或新草稿。恢复已有草稿只补缺失附件，保留既有文案与冻结归档。
- 正式 release.published 事件使用 OIDC 发布草稿阶段的同一份包到 npm latest，确认后自动更新 main 的精确版本插件清单和发布回执；工作流成功才算全部完成。普通提交不重复创建发行，不移动已固定标签或覆盖已发布包。
- 不要求先发布 next、安装候选来源、提交宿主验收证据或另行 promote。开发与自动验证工具按实际用途保留，已安装插件不后台自动升级。

## 总目录

- 分类顺序为主线、支线、故事集、集成战略、生息演算、四月辑录、其他；类内保留源站顺序。普通“剧情”合集归故事集，零散特殊入口归其他并保留具体类型。
- 每张卡片对应一部剧情，显示封面、名称、类型与进度；点击始终进入该部篇目列表。分类导航定位到对应分区。
- 返回主页恢复本次会话的目录浏览位置，窗口变化时优先保持同一段卡片；已经在主页时不跳到顶部。
- 卡片 hover 只显示手形，不变色、不上浮；键盘焦点可见。封面重试是独立按钮，不触发进入剧情。
- 首页进度为白底圆环。从未实际阅读显示 0%；有记录但分母或修订尚未核实时显示短横线与可访问说明。
- 每次重新打开阅读器检查一次目录，有缓存先展示再更新。手动“刷新目录”与自动检查共用流程，重复请求合并；失败保留可用目录并允许重试。
- 目录刷新不重新下载所有正文／图片，不改变阅读记录、设置或当前正文位置。

### 类型与乐章

- 同一总目录通过双选控件切换“按类型／按乐章”，记住偏好；刷新图标仍专用于刷新资料。按类型保留七类及源顺序，剧情卡片补充可核实的所属乐章。
- 乐章归属、排列和连接点来自 PRTS《关卡一览/曲谱》，与现有目录按明确名称／主线 EP 编号对应，不按地区、人物或日期猜测。未收录或未对应的现有剧情仍在“其他”中可读；源站尚未对应的名称明确列出，不创建虚构篇目。
- 乐章视图左侧提供乐章分区导航；电脑保留横向交错剧情轴、鼠标拖动、原生横向滚动和“浏览线”，隐藏上方原生横向滚动条。手机窄屏改为纵向滑动与乐章选择器。模式切换及返回主页保留会话内浏览位置。
- 连接点独立放在两部剧情之间，保留来源顺序及方向，不显示“跨乐章关联”标题。点击定位并突出目标乐章中的剧情；提供返回原连接点的入口，恢复来源位置和焦点。连接是关联导航，不承诺精确时间线或推荐阅读顺序。
- 乐章资料独立加载、缓存和重试，失败不影响现有类型目录、正文或阅读记录。网页和客户端共用同一份实现。

### 封面

- 封面进入可视区域时自动获取，独立于正文图片开关。主页和篇目页统一使用 **1560:500** 外框。
- 标准 1560×500 原图完整显示；主线 EP00—EP04 的 512×512 原图、通用危机合约的 463×121 图完整等比显示并填充背景，不裁切或拉伸。
- 四月辑录通过 APF-YYYY/NBT 与活动索引的年份链接定位横幅；图片 URL 经 MediaWiki imageinfo 取得，不拼接地址。
- `prts:主线剧情/特殊 · 剧情` 显示“主线补充剧情”；`prts:活动剧情/特殊 · 剧情` 显示“活动补充剧情”。使用参考已认可网站线描图制作的两张应用原创封面（深蓝黑、米白线描和少量金色），标题由页面渲染，保留完整图与 1560:500 外框。目录卡片和篇目页的小封面均常驻显示“非官方图片”，无障碍名称也包含该说明，窄窗口不隐藏。按稳定 ID 区分，不按同名标题猜测，不标成 PRTS 原图。
- 其他未经批准的尺寸显示“封面尺寸待适配”。来源缺失、网络失败和解析不兼容分别显示，不合并为“暂无封面”。

## 篇目列表

- 页头显示可取得的 PRTS 整部剧情导语：活动使用“模板:活动信息/quote”的同名分节，主线使用“关卡一览/主题曲”的对应章节导语。无来源时省略，网络或解析失败提供单独重试，不生成剧情梗概。此介绍只在篇章目录展示，现有逐篇关卡简介保留。
- 篇目沿水平主线上下交错，从左到右排列；通过拖动、横向滚动或浏览线查看，不放前后翻页按钮。独立网页版的手机窄屏使用下节规定的纵向列表，桌面端仍保留横向布局。
- 每篇显示编号、名称、可取得的 PRTS 关卡简介和阅读百分比，不放缩略图。没有简介时隐藏该行。
- 整张篇目卡片可点击并从篇首打开；拖动不误触。简介的“重试”只重试简介。
- 有阅读记录时，页头显示“继续阅读 + 章节名称”，恢复该部剧情最后位置。
- 页面显示正文准备进度和准备完成后的总字数；部分失败保留成功结果并可重试。
- “清除本剧情阅读记录”经页面确认后只清该部记录，保留其他剧情、设置、缓存与字数统计，并留在当前目录。

## 正文与导航

- 正文纵向连续滚动；每段发言只显示一次姓名，右侧可含多段文字。旁白与对白正文左对齐。
- 左侧篇目列表标记当前章节，点击其他篇目从篇首打开；窄窗口收为可展开侧栏。
- 顶部“最近阅读”指向最近实际打开的文字篇目，浏览其他目录不会替换；点击恢复最后位置，正在阅读同一篇时不重建页面或跳位。
- 主页上的“篇章目录”入口指向最近实际阅读的剧情。无阅读记录时隐藏相关入口。
- 重新打开阅读器优先恢复上次章节与段落位置；没有可恢复记录时显示目录。
- 正文末尾仅显示“本篇结束”，删除上一篇／下一篇文字按钮。电脑宽屏正文左右留白各作为整条点击区，左侧切上一篇、右侧切下一篇，箭头仅作方向提示；不占正文空间，不覆盖姓名／CG／选区，留白上的滚轮仍原生滚动正文。点击区保持透明，悬停只显示手形，箭头不变色；保留可见的键盘焦点与首尾禁用状态。顶部保留图标切篇入口，窄窗口和手机不设置常驻两侧点击列。
- 手机正文左滑切下一篇、右滑切上一篇；拖动时预览目标篇名，达到明确距离后松手切换。不将竖向滚动、文字选中、多指缩放、图片／控件操作或屏幕边缘返回手势解释为切篇；保留顶部按钮作为非手势入口，并提供可关闭的首次提示。切篇前保存原位置，不因切篇操作将原篇标成读完。
- 各平台顶部仅通过图标按钮手动展开／收起；滚动不改变状态。收起释放布局空间并尽量保持当前内容锚点，展开后设置、进度及导航入口可用。用户已撤回手机自动隐藏方案。乐章导航选择随模式浏览位置和关联返回恢复，顶部展开／收起保持当前选择。
- 所有选项及分支按组保留，共同后续只展示一次；分支独立维护人物与图层状态。
- 视频显示明确的 PRTS 来源入口，不内嵌播放。纯视频篇不创建文字记录或改变最近阅读；混合篇正常保存文字进度。

### 图片与人物

- 姓名不显示“点击查看立绘”说明或下方点状下划线。“自动显示图片”默认关闭，此时鼠标 hover 不显示或请求立绘，只通过点击、触摸或键盘开关；点击外部、焦点离开或 Esc 关闭。浮层提供立绘切换、图片和来源链接，必要时说明匹配或加载状态。
- 开启“自动显示图片”后，鼠标 hover 姓名取得立绘，离开姓名与浮层自动关闭；允许跨过两者间的小间隔，浮层中的来源和重试仍可操作。点击姓名将悬停预览固定显示，移开鼠标或悬停其他姓名不替换／关闭；再次点击该姓名、点击外部或 Esc 关闭。触摸／键盘仍可显式开关。滚动接近 CG 时取得并原位显示；关闭开关不删除缓存。
- 显示姓名保持原文，包括匿名姓名。人物资源由场景槽位／来源映射决定，焦点不等于说话者。
- 多人场景优先按精确资料名、明确干员 ID 与场景资源对应；也可用同篇同分支容器内的单资源发言建立唯一一致的姓名／资源组关联。匹配场景指定表情时，对应资源必须仍在当前场景中；发言人未在画面中时，只能按下述独立展示规则使用其默认立绘。无法解释的身份／造型冲突、跨章节／分支或匿名标签不用于确认身份。角色与造型已确认、只有多个表情无法选择时使用来源明确的同组同造型默认立绘；不同角色或造型之间不随意选择。不能确认时使用中性占位，不靠焦点、相似姓名或逐角色特例猜测。
- 能唯一确定剧情指定表情时优先用该表情（包括来源明确的旧版映射）；角色与造型已确认，但场景中多个表情无法唯一选择，或指定表情条目／图片确实缺失时，才使用同一资源组、同一造型的有依据默认立绘。角色本身无法确认时不显示猜测图片。网络故障和源映射解析异常保留各自错误类型，不伪装成默认图成功；界面按下述规则精简展示。
- 单人画面未换图却切换发言人时，不能把该画面中的角色直接当作后续发言人。若发言人在同篇同分支有独立且一致的单人展示，其他冲突全部来自沿用另一位已一致确认角色的画面，可排除这些画面沿用造成的假冲突；独立展示本身存在不同角色／造型、匿名画面归属或其他无法解释的冲突时仍不确认。当前场景中存在发言人时保留指定表情；画面只显示其他人或没有角色画面，但发言人及造型已由上述独立来源确认时，显示发言人自己的有来源默认立绘，结构化结果保留原因，不能使用画面中其他人的图替代。没有画面不标成角色不一致。该回退不突破跨篇／分支或未知造型的限制。
- 有可选图片时，立绘浮层使用方形双段选择，左侧“默认立绘”、右侧“场景立绘”；角色一致时也保留控件，默认与场景指定表情仍可不同。直接悬停两个选项时分别解释“该角色当前造型的基础立绘，不代表本句剧情表情”和“剧情当前画面使用的立绘，可能与发言人不一致”，不另加 i 图标；控件提供相同的无障碍说明。首次打开优先明确的场景表情；已确认场景只显示其他人时使用发言人默认立绘。切换只影响当前浮层，不改设置或阅读记录；使用原生单选控件，支持左右方向键。两种图片都不可用时隐藏双选框。
- 允许显式查看与发言人不一致的原场景立绘，图片上方常驻“场景立绘与发言人不一致”，由选中项标识当前显示方式，图片下方不重复说明。无法确认对应关系时在图片上方写“尚未确认角色与立绘的对应关系”；原场景有多个候选时并列显示，不任取其中一人，也不把查看原图视为身份已确认。只有一侧图片不可用时对应选项置灰。
- 正常／默认立绘成功显示后，下方只保留来源链接，不显示解释段落或刷新按钮。无可用立绘时只显示“暂无可显示的立绘”和 PRTS 来源链接，不显示灰色人形、详细诊断或重新核验按钮；该文案不等于确认源站没有图片。身份、造型、引用、来源缺图与解析等状态仍在结构化结果中区分。立绘仅在网络加载失败时显示简短失败提示和重试按钮，不显示灰色人形；封面与 CG 的原有重试规则保留。
- CG 支持 Image／ImgEffect、CGItem 静态图层及 largebg／verticalbg 的 cggroup 拼接；保留透明通道和完整图层。常规舞台背景、imagegroup 与动态演出不作为正文 CG。

## 字数、位置与进度

整体进度为各篇已读字数之和除以该部剧情完整的文字总字数，不对篇目百分比取平均。

- 字数按非空白 Unicode 码点计，包含对白、旁白、选项及全部分支；姓名、界面标签、演出指令、图片、视频和来源说明不计入。共同后续只计一次。
- 打开某部剧情后，以最多两篇并发准备该部全部正文，取得分母；目录先展示，用户可边加载边阅读。不预取其他剧情或正文图片／映射。
- 准备只更新公共缓存与字数，不写阅读记录。离开剧情停止排队，已发请求可完成；再次打开复用缓存并补取缺失篇目。
- 缺失或解析失败的正文保持未知，不当作零字数。纯视频明确排除在文字分母之外，含视频剧情的进度注明只统计文字。
- 每篇按最远位置估算已读字数，回看不倒退、重读不重复累计；未打开的中间篇目不会因跳章而算作已读。同篇拖到后方会推进最远进度。
- 最后位置与最远进度分别保存：续读跟随最后位置，百分比使用最远位置。只有完整到达末尾才显示 100%。
- 位置以段落标识与段内比例保存，不只存滚动像素。正文修订后先匹配确认内容；不能可靠恢复时回到较早确认位置或篇首，并保留迁移信息，不伪造已读比例。

## 设置与数据管理

- 主题提供“主题跟随系统”和“深色模式”开关；跟随时后者反映有效主题并禁用。关闭跟随后保留当前有效主题，偏好持久保存。
- 内容缓存默认按最后使用时间保留 7 天，可调整为 1—365 天；无总容量上限。关闭应用期间不运行定时清理。
- “刷新本章”重取当前正文并更新字数；内容变化只在实际打开正文时迁移记录，后台准备不迁移。
- 全剧情横杠分别解释总字数未完成与旧阅读记录待核实。篇目目录列出待核实记录与恢复入口，不清除历史或把未知进度改成 0%。
- “清理图片缓存”只清图片；“清理剧情文本和图片缓存”清正文、资料、映射和图片。两者均保留阅读记录、偏好和公共字数。
- 清全部内容时停止准备队列，不立刻补下载；重新打开或主动重试后才恢复获取。清理前的迟到请求不能回填。
- “清除全部阅读记录”经确认后回到主页并隐藏最近阅读；保留偏好、缓存和公共统计。清除前的旧页面保存不能使记录复活。

## 布局与动效

共享样式控制颜色、字号、间距和时长。通过重排、换行和侧栏收起适配窗口，不整体缩放画布。

正文版心根据阅读面板的实际可用宽度适度扩展，并设置行长上限，减少电脑宽屏的两侧留白；网页与插件共用规则，不按整个屏幕宽度判断。手机和窄侧栏保持紧凑排版；两侧切篇点击区随版心边界同步收缩，不覆盖正文、姓名或图片。

封面在目录卡片与篇目页页头之间迁移，正文纵向揭幕；相邻篇目用方向相反的横向渐进替换。顶栏和来源提示不参与内容转场；连续操作、缩放和减少动态效果均保持相同终态，不采用铺满屏幕的封面放大或 3D 卷页。

设置从右侧滑入，减少动态效果时直接显示。设置打开期间刷新正文直接保持原位更新，不重放正文揭幕；文档转场截图不得盖住设置与遮罩，打开设置会结束已有页面转场。

[界面预览](design/README.md)直接使用当前组件和样式。界面验收覆盖 320px、中等、桌面和低高度窗口，以及双主题、键盘、触摸和减少动态效果。

## 独立网页阅读器

- 与介绍页使用同一静态站点，在 `/reader/` 打开真实阅读器；介绍页增加“打开网页版”，保留演示和桌面安装入口。六部演示剧情使用与封面对应的《孤星》《长夜临光》《巴别塔》《愚人号》《叙拉古人》《火山旅梦》名称，其余演示文案和人物保持占位，常驻非原作说明。
- 网页运行时由浏览器直接匿名请求 PRTS 的公开跨域 API 和明确来源的资源，不需要 Node、MCP、本机 HTTP 服务、模型或自建业务后端。仅构建及本地静态预览使用 Node。
- 复用现有三个页面、解析器、分支、立绘判断和字数进度服务。网页构建单独选择浏览器存储与兼容适配；桌面端仍使用原始页请求、SQLite、既有缓存和 MCP 入口，不替换已安装插件或其数据。
- 网页手机窄屏将篇章目录改为按顺序纵向排列，整页自然上下滚动，不显示浏览线或横向浏览提示；保留篇目编号、标题、简介、进度和整卡点击。电脑宽屏继续保留横向交错篇目轴和浏览线。此响应式调整只用于真实网页入口，不改变桌面插件。
- 网页只持久保存各章阅读位置、最远进度、修订定位摘要、必要字数统计和设置。使用独立浏览器数据库，与占位演示及桌面记录隔离；不自动跨设备同步。
- 目录、正文、人物映射与图片只在当前网页运行期间临时复用，不写入 IndexedDB、localStorage 或 Cache Storage。封面按可见范围加载，不预取或持久缓存全部封面；浏览器正常 HTTP 缓存不强制禁用，不提供整库下载或离线阅读保证。没有持久内容缓存时设置不显示缓存保留期或离线清理选项。
- 保留按需图片、当前剧情两篇并发准备、未知分母、分别保存最后位置与最远位置、修订迁移以及清除记录代次保护。刷新、关闭重开和切入后台时保存位置；存储失败或源站不可用明确提示，不静默清空记录。

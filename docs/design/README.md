# 页面与动效参考

2026-11-01 迁入用户已认可的交互方向。文件保持原设计版本，不代表正式应用实现。

- [reader-preview.html](reader-preview.html)：可直接用浏览器打开的预览，包含三个内部页面和转场。
- [reader-prototype.html](reader-prototype.html)：原始 HTML 片段，适合查看布局、样式及交互逻辑。
- [prototype-checks.snapshot.json](prototype-checks.snapshot.json)：迁入前浏览器检查的历史快照。

## 重点保留

- 总目录的分类导航、参考卡片和封面迁移。
- 篇目列表从左到右交错排列，可拖动横轴，不放前后翻页按钮。
- 阅读页连续纵向滚动、左侧篇目列表、整段姓名与正文分栏、左对齐旁白。
- 顶部最近阅读章节可点击续读，浏览目录时不改变；读同一章节时不重置当前位置。
- 名称 hover 显示提示，点击立绘开关；正文 CG 原位展开。
- 卡片与篇目列表之间柔和衔接，正文揭幕，返回主页无全屏封面放大。
- 根据窗口重新排版，窄窗口收起阅读侧栏，遵守减少动态效果偏好。

## 示例与运行依赖

正文为原创示例，角色立绘为位置示意，部分封面为抽象示意。“骑兵与猎人”封面来自用户提供的截图并嵌入文件；发布阶段需另行处理实际素材来源与分发范围。

封面已内嵌，预览不依赖原截图路径。预览包装器仍有 CDN 辅助资源；没有网络时部分图标、提示或设计控件可能不可用。正式插件应采用正常项目依赖与打包，不依赖 Codex 的 Tweak 全局变量。

迁入的历史快照覆盖目录进入/返回、横轴拖动、续读位置、进度保留、立绘与 CG 操作、清缓存保留进度、状态恢复、320px 布局和减少动态效果。新项目仍需验证自身实现，尤其是实际宿主与真实数据。

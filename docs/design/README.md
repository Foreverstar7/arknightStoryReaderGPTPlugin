# 当前界面预览

预览入口直接使用 `src/ui/main.tsx` 和正式组件／样式，不维护另一套界面实现。

1. 按 [README](../../README.md#使用原创样例预览)启动隔离的 fixture 开发服务。
2. 打开 [当前界面](http://127.0.0.1:5173/docs/design/reader-preview.html)。此入口通过 Vite 运行，不能直接双击 HTML。
3. 检查总目录 → 篇目列表 → 正文，以及最近阅读、图片开关、返回和相邻篇切换。

fixture 使用原创正文和示意图片，页面会明确标注数据来源。真实内容验证另选 PRTS 来源，不将游戏截图嵌入文档或包中。

界面规则见[阅读行为](../requirements.md#布局与动效)，操作与窗口检查见[验证指南](../testing.md)。

## 目录双视图方案样例

[catalog-modes-preview.html](catalog-modes-preview.html) 是按用户请求制作的独立交互样例，可直接双击打开。它用于比较“按类型／按乐章”，不接入正式阅读器，也不替代上面的当前实现预览。

该方案现已接入共享 ReaderApp；正式数据由 PRTS 索引解析，交互与来源规则以 [需求](../requirements.md#类型与乐章) 为准。此 HTML 保留为已讨论布局的参考，其中虚构进度及节选表不参与生产构建。

- 默认打开“按乐章”的“方舟”分区。桌面使用可横向滑动、鼠标拖动的故事卡片轴及浏览线，隐藏浏览线之上的浏览器原生横向滚动条；窄屏改为纵向卡片和乐章选择器。鼠标拖动沿用篇目目录的 6px 判定，拖动不打开卡片或关联入口，触摸保留原生滚动。
- 关联入口是两部剧情之间的独立分叉节点，移除了“跨乐章关联”标题。点击《生于黑夜》与《遗尘漫步》之间的入口可定位到主线第七章，再用“返回来源位置”回到原处；反向入口显示在目标章节之前。两种目录模式分别保留本次页面内的浏览位置。
- 类型卡片展示所属乐章；“其他内容”保留集成战略、生息演算及联动样例。卡片点击只打开占位篇目列表，刷新按钮只演示反馈，明暗主题均可切换。
- 为了让用户离线查看提案，样例内置节选剧情名、关系及虚构篇数／进度；名称与关系取自 2026-11-08 核对的 [PRTS 曲谱目录](https://prts.wiki/w/关卡一览/曲谱)。这不是生产目录，不推断事件日期或官方推荐阅读顺序。正式接入前需重新核对来源，并通过共享数据层取得归属与关联。
- 复用网站已有六张原创线描封面，其他封面为内置几何示意图；相对资源位于 `website/assets/`。不调用远端接口，不读写真实阅读记录、浏览器存储或插件数据。

Windows Edge 157.0.4341.42 已检查模式切换、浏览位置恢复、跨乐章往返、横轴外目标定位、卡片弹窗、键盘与减少动态效果；补查桌面／窄屏的中间节点、拖动防误触、横向滚动和浏览线到达两端，320×760、768×900、1440×960、1024×400 双主题均无整页横向溢出。此结论仅针对独立样例，不代表正式网页或 MCP 宿主已接入。

上述验证在隐藏原生横向滚动条之前完成；本次仅改该样式，按用户要求未运行测试。

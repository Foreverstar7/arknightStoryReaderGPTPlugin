# 0.1.15：主页位置与横幅封面

日期：2026-11-02。基线：`27af3f9`（0.1.14）。本轮为用户的新反馈，不启动 S4；不推送或发布。

## 行为

- 从篇目页或正文点击“主页”，恢复本次打开期间上次离开目录的位置；已在主页时再次点击保持原位。
- 主页实例保留，离开时隐藏，已加载封面不因来回切页重置。隐藏时未看过的卡片不触发封面获取，控件不进入辅助功能和键盘导航。
- 离开前保存首个可见剧情与相对偏移，返回时在新转场快照之前恢复。窗口宽度改变时仍定位到同一段目录；原滚动像素只作无锚点时的回退。该状态不写入阅读记录，不承诺刷新或重启后的主页位置恢复。
- 主页与篇目页的封面区域统一采用 1560:500 比例，只显示实际原图为 1560 × 500 的封面，保留完整画面。其它尺寸显示“封面尺寸待适配”，仍可进入该剧情；不会强行拉伸、裁切或用别的图片替代。
- 窄窗口将篇目页横幅与标题上下排列；正文 CG、立绘、编码格式和透明图层不受封面策略影响。

## 选择与边界

最初使用卸载后恢复位置，位置测试通过，但实际预览返回集成战略时抓到部分已加载封面在转场中再次显示“加载中”。最终保留主页实例，接受已看过封面在本次 UI 生命周期内驻留的内存成本，不引入额外图片缓存层。未做两方案的定量内存或性能比较。

1560/500 固定值来自用户在本轮的明确选择，属于临时展示策略；PRTS 本身并非所有封面都是此尺寸。实现位于 `SourceImage.tsx` 与共享样式变量 `--cover-ratio`，以后改变策略时同步修改需求、常量、样式和横／竖图验证。来源解析和原图保持可用，不能把暂缓展示称作源站缺图。

根据现有 `prts-cover-coverage.json` 的 117 部清单，102 部使用 1560 × 500（101 张独立文件），7 部四月辑录竖图暂缓展示，8 部来源仍待适配；目录和正文范围不变。

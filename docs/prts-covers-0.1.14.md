# 0.1.14 图片格式修复与目录封面覆盖

核对：2026-11-02。用户最初要求处理大量无图、验收并本地提交，随后在本轮验收期间明确改为“执行完这里就停下”，不再前往 S4。本轮保留并完成了原 0.1.13 未提交工作；没有预取未读正文或全部图片，没有新开 S4 对话、推送、发布或上架。

## 原因与修复

现有 117 部／1756 篇目录中，109 部可从明确来源解析封面并由 MediaWiki `imageinfo` 确认文件存在，其中 **87 部为 JPEG，22 部为 PNG**。旧元数据、尺寸检查、缓存和工具图片契约均只接受 PNG，因此只改文件名后缀不足以解决问题。

- 活动字段现在接受 PNG、JPEG（含 `.JPG`／`.jpeg`）、WebP、GIF；用 `image-size` 识别实际字节格式与尺寸，并与响应 MIME 核对。HTML 错误页、类型不符和不兼容内容仍明确失败；图片大小上限、来源域名和按需触发不变。
- 原字节直接经 `_meta.readerImage` 传给页面的 SVG 图层，不转码；人物 PNG alpha、底图＋表情的坐标及尺寸不变。旧 PNG 图片缓存继续可读；旧空／无来源／parserVersion 2 封面资料按需重验，升级为版本 3，不清阅读记录。
- 四月辑录以目录中唯一 `APF-YYYY/NBT` 入口确定年份，允许同组包含其它小游戏篇目；读取[四月辑录索引](https://prts.wiki/w/愚人节活动?action=raw)中 `apr-entry` 卡片**显式指向相应年份的图片链接**。文件名来自原文，不拼图名，也不依赖标点不一致的显示标题。
- 主线的同名资料及其明确重定向可以复用活动标题字段，已核对第 5 至 17 章共 13 部；纪念活动图保留其最终资料来源。第 0 至 4 章仅确认[主题曲索引](https://prts.wiki/w/关卡一览/主题曲)的章节名称图，继续显示来源待适配，不以 Logo 或任意 CG 代替封面。
- 封面缓存键优先使用稳定故事 ID，避免两组同名“特殊 · 剧情”共用资料结果。资料／资源缺失、来源待适配、请求失败、解析失败及独立刷新重试保留；网络错误补齐资料页来源。

新增依赖为 **image-size 2.0.4**，npm `latest` 实查为该稳定版，官方 engines 为 Node ≥18，与固定 Node 26.13.0／npm 12.2.1 兼容。选择依据是[维护方文档](https://github.com/image-size/image-size)：支持缓冲区、JPEG／PNG／WebP／GIF、内置类型且无需原生运行时；只需尺寸与格式，避免自写 JPEG 二进制解析器或引入转码。该库只检查图片头，不能保证整图可解码，因此保留浏览器解码错误及刷新当前资源链的恢复路径。安装审计为 0 个已知漏洞，锁文件已更新。

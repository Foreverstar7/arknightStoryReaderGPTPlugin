# 1.0.1 体验修正记录

本页保留 2026-11-07 的变更与验证摘要。当前行为以 [需求](requirements.md)为准，发行状态见 [STATUS](../.ai/STATUS.md)。

## 变更

- 姓名保留原生按钮和可见焦点，移除点击提示与点状下划线。自动图片模式支持悬停预览、离开关闭和点击固定，触摸与键盘继续可用。
- 多人场景增加同篇同分支的一致单资源证据，保留精确干员资料优先级；不使用姓名例外或 focus 猜人物。后续假冲突处理与双选控件见 [立绘说明](portrait-speaker-evidence.md)。
- 进度横杠区分缺少总字数与旧记录待核实，篇目目录提供恢复入口，后台准备不迁移记录。
- 两个补充合集使用原创意象封面，目录卡片与篇目页均常驻标明“非官方图片”；[原图和提示词](design/supplement-covers/PROMPTS.md)随仓库保存。
- 设置从右侧滑入，减少动态效果时直接显示；打开设置结束已有转场，刷新正文保持模态层可见，关闭后恢复焦点。
- 网站滚动演示增加完整画面停留，保留原生滚动、倒放和减少动态效果；插件清单包含同源明暗 SVG 图标。当前网站分镜与维护方法见 [网站说明](website.md)。

## 验证摘要

当时已执行类型／单元／格式检查、插件及网站构建、fixture 浏览器回归、网站交互与真实 PRTS 图片专项。实际 1.0.1 归档通过生产依赖、离线 npm 安装、三种 MCP 启动入口、UI HTML 及图标一致性检查。

多人绑定审计基于 1,756 篇公开样本，无解析失败；覆盖数量包含原有资料匹配，不能当作净新增修复数或完整图片端到端证明。定向样例实际加载了 NPC 图片，覆盖匿名、冲突、造型、分支和共同后续。

网站的悬停、固定、键盘与触摸路径已通过 [Pages 检查与部署](https://github.com/Foreverstar7/arknightStoryReaderGPTPlugin/actions/runs/42385390356)。

上述是版本阶段的历史验证，不覆盖后续代码或替代真实桌面验收。重跑方法见 [验证指南](testing.md)，不依赖当时的本机归档或截图。

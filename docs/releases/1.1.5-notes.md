# v1.1.5 · 乐章目录与阅读导航

- 总目录支持“按类型／按乐章”，剧情卡片显示所属乐章；未收录剧情保留在“其他”。
- 乐章视图提供分区导航、交错剧情轴、浏览线和剧情之间的关联入口，可定位目标并返回原处；手机使用纵向列表。
- 顶部增加图标式展开／收起，手机下滑自动隐藏、上滑恢复，手动收起保持到主动展开。
- 正文移除末尾上一篇／下一篇按钮；电脑可点正文外侧箭头，手机可横滑预览并松手切篇，顶部保留按钮入口。
- 网页和插件共用界面与数据解析；乐章资料读取失败时保留现有目录与阅读能力，阅读记录和进度规则沿用原实现。

网页部署与插件发行分别记录，已安装插件需要更新后才能使用新功能。实际验证范围见[项目状态](https://github.com/Foreverstar7/arknightStoryReaderGPTPlugin/blob/main/.ai/STATUS.md)。

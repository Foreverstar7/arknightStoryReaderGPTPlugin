# v1.1.4 · 搜索直达侧栏阅读器

- 点击桌面搜索卡片可直接打开侧栏阅读器，并定位到对应剧情的篇章目录，保留命中篇目标记。
- 阅读器已打开时可切换到新目标；重复点击同一剧情可返回篇章目录，跳转前保存当前阅读位置。
- 侧栏打开失败时可重试或选择在当前窗口打开；其他宿主和网页预览保留原有阅读方式。
- 包含未发布的 1.1.3 调整：移除搜索结果页常驻的“刷新搜索资料”按钮，保留失败重试和结果分页。
- Release 草稿自动填写对应版本的标题和说明，完成自动验收后只需点击一次 Publish release。

浏览器及 MCP 协议验证与真实桌面体验分别记录，当前支持范围见[项目状态](https://github.com/Foreverstar7/arknightStoryReaderGPTPlugin/blob/main/.ai/STATUS.md)。

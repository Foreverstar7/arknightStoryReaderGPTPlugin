# v1.1.6 · 乐章目录与阅读导航

- 总目录支持“按类型／按乐章”，剧情卡片显示所属乐章；未收录剧情保留在“其他”。
- 乐章视图提供分区导航、交错剧情轴、浏览线和剧情之间的关联入口，可定位目标并返回原处；手机使用纵向列表。导航选择随浏览位置恢复，展开／收起顶部后保持选择。
- 顶部仅通过图标手动展开／收起，滚动时保持当前状态。
- 正文移除末尾上一篇／下一篇按钮；电脑点击左右留白切篇，箭头保留作提示，悬停只显示手形。点击区保持透明，不占正文，滚轮继续滚正文。
- 手机可横滑预览目标并松手切篇，顶部保留按钮入口；文字选区、图片控件、边缘返回和多指操作不误切。
- 网页和插件共用界面与数据解析，阅读记录和字数进度沿用原规则。乐章资料读取失败时保留现有目录和阅读能力。

网页部署与插件发行分别记录，已安装插件需要更新后才能使用新功能。实际验证范围见[项目状态](https://github.com/Foreverstar7/arknightStoryReaderGPTPlugin/blob/main/.ai/STATUS.md)。
